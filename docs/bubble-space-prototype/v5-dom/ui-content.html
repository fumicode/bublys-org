2. 中身で増える札は 3枚だけ。 自由に置く・並べる・送って見る はどの空間でも出る （順序と自由座標は全部の泡が持つから）。勤務表の 制約・スタッフ・カレンダー を「送って見る」にもできてしまう。 中身が効くのは 表で見る・履歴で見る・版を奥へ の3枚。

3. 覚えられない。 押せる札が空間ごとに 2〜5枚で変わる。だから出ない札も灰色で残し、理由を書いた （「中身が 版 を持たない」）。消すと、できることが画面から消えて学べなくなる。

4. 「重ねて置く」が札にならなかった。 中身から出る条件が書けない。 自由に置く に混ぜて Z＝順序 にすると、外の空間で 議事録の倍率が 1.000 → 0.810 に落ちた（v4 で実測）。 だから「詳しく」の中に置いた。v4 の8プリセットのうち 1つが札から漏れている。
