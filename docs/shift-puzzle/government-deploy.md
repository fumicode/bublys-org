# 行政版シフトントンを Vercel に出す

公開中のシフトントン（ホテル版）と同じコードを、環境変数だけ変えて別の Vercel プロジェクトでビルドすると、
行政版になる。この文書は、その Vercel プロジェクトを作る人のための手順。経緯と決定は Issue #234。

## しくみ

- コードは1つ（`main`）。ホテル版と行政版の違いは、ビルドするときの環境変数 `VITE_SHIFT_FORMATS` だけ。
- URL（オリジン）が違えば、ブラウザのデータ（localStorage・IndexedDB）も別々になる。行政版とホテル版の
  データは混ざらない。

| | ホテル版（いまの公開版） | 行政版（これから作る） |
|---|---|---|
| `VITE_SHIFT_FORMATS` | 未設定（または `hotel`） | `government` |
| 選べる形態 | ホテル | 行政 |
| 組織の呼び方 | 店舗 | 課 |
| 選べる区切り方 | 暦月 | 4週・暦月 |
| 初めて開いたとき | 例データ（ホテル）が入り、作成途中の勤務表が開く | 空のまま。課の一覧と勤務表一覧が開く |

## 前提

- 行政版の変更（ブランチ `kanetaku1/issue234-period`）が `main` にマージされていること。
  このブランチは #232 の上に積んであるので、#232 → このブランチの順に `main` へ入る。
- **ホテル版の Vercel プロジェクトの設定は変えない。** 環境変数 `VITE_SHIFT_FORMATS` を足さないこと
  （足すと公開版の画面が変わる）。

## 手順

1. Vercel で、同じリポジトリ（`fumicode/bublys-org`）から新しいプロジェクトを作る。
2. **Root Directory** は、ホテル版のプロジェクトと同じ `hotel-shift-puzzle-bubly/hotel-shift-puzzle-app`。
   - ビルドの設定はこのディレクトリの `vercel.json` に書いてあるので、画面で上書きしなくてよい
     （インストール `cd ../.. && npm install`、ビルド `npx nx build @bublys-org/hotel-shift-puzzle-app`、
     出力 `dist`、フレームワーク Vite）。
3. **Environment Variables** に次を足す。Production と Preview の両方に入れる。

   ```
   VITE_SHIFT_FORMATS=government
   ```

   Vite の環境変数は**ビルドするときに焼き込まれる**。あとから値を変えたら、デプロイし直さないと反映されない。
4. Production Branch は `main`（ホテル版と同じ）。`main` に push すると、ホテル版と行政版の両方がデプロイされる。
5. デプロイする。プロジェクト名・ドメインは任せる。決まったら Issue #234 に書いてほしい。

## デプロイしたあとに確かめること

行政版の URL を、**一度も開いたことのないブラウザ（またはシークレットウィンドウ）**で開く。

- [ ] 空のまま開き、「課一覧」と「勤務表一覧」のバブルが出る（ホテルの例データが入っていない）
- [ ] 左のメニューに「課」がある（「店舗」ではない）
- [ ] 課を作ると、形態の選択欄は出ず、区切り方は「4週」、起算日は今日を含む週の日曜になっている
- [ ] 勤務表一覧の「新しい勤務表を作成」で、作った課を選ぶと、期の選択肢が「2026/11/8〜12/5」のような
      4週の期になる。課を作る前は「先に課を作ってください」と出る
- [ ] 4週の期の勤務表を開くと、28日ぶんの列が出る。見出しの「シフト希望」から、その期の希望の一覧を開ける
- [ ] ファイルのバブルに「例データ読み込み」が出ない

あわせて、**ホテル版の URL** でも次を確かめる（環境変数を足していないので、何も変わっていないはず）。

- [ ] 初めて開くと例データが入り、作成途中の勤務表（2026年8月）が開く
- [ ] メニューは「店舗」で、店舗を作るときに形態・区切り方の選択欄が出ない（ホテル・暦月だけ）

## 手元で行政版を動かす（開発者向け）

`hotel-shift-puzzle-bubly/hotel-shift-puzzle-app/.env.local`（git には入らない）に書いて dev サーバーを起動する。

```
VITE_SHIFT_FORMATS=government        # 行政版と同じ
VITE_SHIFT_FORMATS=hotel,government  # 両方を選べる（先頭が既定）
```

## まだ無いもの

- 行政の例データ（現場のヒアリング待ち）
- 4週の期で守る時間の上限（4週155時間など）
